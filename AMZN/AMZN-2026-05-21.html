摘要

Amazon 為全球最大電商 + 雲端基礎設施 + 數位廣告綜合集團，FY25 營收 $716.9B（+12.4% YoY）[來源:10-K]，三大事業：北美零售 + 國際零售（占 ~84%）、AWS（cloud + AI 基礎設施、占 ~16% 但占營業利潤 ~70%）、廣告（高速成長子業務、估 FY25 $60B+）。Q1 FY26（截至 2026-03-31）營收 $181.5B（+16.6% YoY）[來源:10-Q]，營業利潤 $23.85B（+27% YoY）、營業利潤率自 5y 均 7.2% 升至 TTM 11.5%（+4.3 pp）[來源:Finnhub]。

論點核心：(1) 結構性利潤率擴張——AWS AI 基礎設施 + 廣告 mix 升級 + 北美零售 fulfillment 效率改善，三軸合力推升 op margin；(2) 估值 PE_fwd 29.7、PEG_fwd 1.45、EV/EBITDA 15.7[來源:Finnhub] 為 mega-cap AI 龍頭中最合理（NVDA 22 但 PS 25 vs AMZN PS 3.8；GOOGL 29、AAPL 30）；(3) 賣方買入占比 92.3%（78 位中 0 sell）[來源:Finnhub]——僅次於 NVDA 93%；(4) 過去 4 季 adj EPS 2 beats + 2 misses（Q4 FY25 -3.0%、Q1 FY26 -3.6%），最近 2 季 miss 反映短期執行不均，但幅度溫和。

給予 買入、6M 目標 $310（區間 $250–360）。最大單一觸發點為 2026-07 底 Q2 FY26 財報：若 AWS YoY 增速重回 +20%+ + 北美零售 op margin 達 8%+ → 升 STRONG_BUY；若 AWS Q2 YoY < +15% 或廣告增速 < +18% → 降 NEUTRAL。

適合相信「AWS AI 與廣告高增速兼具 + 零售規模經濟」、能承受 30% 年波動度（3M ADR std 28.5）的成長型核心配置；不適合對 capex $100B+ 對 FCF 持續壓制敏感的價值型投資人。

產業與業務分析

AMZN 業務拆解（FY25）：北美零售（自營電商 + 第三方賣家 + 廣告 + 訂閱）約 60% 營收；國際零售約 24%；AWS約 16% 營收但占營業利潤估 60-70%[來源:推算]；廣告為高速成長嵌入業務、估 FY25 ~$60B+（+25% YoY）[來源:推算]。產業結構：(i) 電商高度集中——AMZN 在美國電商佔 ~40%、與 Walmart 雙頭；(ii) 雲端基礎設施寡占——AWS / Azure / GCP 三大共 ~60% 全球 cloud 份額；(iii) 數位廣告——AMZN 已是 Google / Meta 後第 3 大全球數位廣告平台。

SaaS / 電商混合 KPI（Q1 FY26）：AWS 營收—未拆出但業界估 $30B+ 單季（+18-20% YoY）[來源:推算]；北美零售 op margin—估 6.5-7%（vs FY22 -0.6%）[來源:推算]；Prime 訂戶數—10-K 揭示全球 ~300M+[來源:10-K]；capex / 營收—FY25 capex 估 $100B+ / 營收 $717B = 14%（高，主要 AWS GPU + 履行中心 + Kuiper 衛星）[來源:推算]；OCF—FY25 全年 $139.5B（+20% YoY）[來源:10-K]。10 年週期脈絡：FY18 EPS $20.14、FY19 $23.01（pre-split）→ 2022-06 20:1 拆股[註1] → FY20 $2.10、FY21 $3.24、FY22 -$0.27（Rivian writedown + cost overrun）→ FY23 $2.90 → FY24 $5.53 → FY25 $7.17[來源:10-K]。三年 EPS 自虧損翻轉 +1,200%。Headwinds：(1) Capex $100B+ 壓制 FCF（FY25 FCF 估 $35-40B vs OCF $140B）；(2) FTC 反壟斷案進行中—10-K Item 1A 明示[來源:10-K]；(3) Anthropic 投資 $8B（FY24-25）—AWS 客戶承諾但戰略合作；(4) 勞工 / 工會問題。

註 1：FY18-19 EPS 為 2022-06 20:1 拆股前面額；FY20+ 數字已調整為拆股後可比較數字[來源:10-K]。

投資論點（Bull Case）

1. 三軸結構性利潤率擴張仍處中段
Op margin 5y 均 7.2% → TTM 11.5% → Q1 FY26 13.1%[來源:Finnhub][來源:10-Q]。AWS（高 GM）、廣告（高 GM）、北美零售（efficiency）三軸合力；FY27 op margin 14%+ 可期。
若任一季 Op margin 回落 > 2 pp、或 AWS 增速跌破 +15%，論點動搖。
2. AWS AI 基礎設施仍處早期擴張
市場估 AWS Q1 FY26 收入 $30B+ / +18-20% YoY[來源:推算]；Anthropic 大額採購承諾 + Trainium / Inferentia 自研晶片[來源:news]。
若 Q2 FY26 AWS YoY 跌破 +15%，或 hyperscaler 客戶遷離至 Azure / GCP，AI 雲端故事弱化。
3. 廣告業務高速擴張
FY25 廣告營收估 $60B+（+25% YoY）[來源:推算]，已是 Google / Meta 後第 3 大全球數位廣告平台；Prime Video 廣告（2024 初）擴大 inventory，未來增長空間大。
若廣告增速跌破 +18% 連 2 季，或 Prime Video 廣告 ARPU 顯著低於預期，論點失效。
4. 賣方共識極強烈偏多
78 位賣方買入占比 92.3%（22 強買 + 50 買入、0 sell）[來源:Finnhub]，與 NVDA 93% / GOOGL 89% 同檔位。Q3+Q2 FY25 大幅 beat（+21.5% / +24.0%）建立信任。
若 Q2 FY26 共識 EPS 連續 3 季 miss，或買入占比連 2 月跌破 85%，動能信號弱化。

估值與目標價

為達成目標價，需要相信什麼

  • Q2 FY26（2026-07 底）營收 ≥ $190B（+17% YoY）、AWS 增速重回 +20%+。
  • FY26 全年 Op margin ≥ 12%（current TTM 11.5%）。
  • FY26 廣告營收增速維持 ≥ +22%。
  • FTC 反壟斷案無 H2 FY26 結構性救濟命令。
  • Q2 FY26 adj EPS 重回 beat（連續 2 季 miss 後第 3 季）。

三角驗證 6 個月目標價：

方法 1（multiple × forward EPS）：Finnhub 隱含 forward EPS $8.93（$265 / PE_fwd 29.69）[來源:推算]。對 mega-cap AI / 雲端適用 PE 28–36x（PEG_fwd 1.45 合理範圍）→ $250–$321，中位 $285。若 FY27 adj EPS 上修至 $9.50（含 H2 ramp），32x = $304；中位 $295。

方法 2（DCF / FCF 敘述）：FY25 OCF $139.5B、capex 估 $100B+ → FCF $35-40B[來源:推算]。FY26E FCF $30-50B（不確定區間，視 capex 節奏）。EV $2.83T / FCF 中位 $40B = 71x；對成長期 mega-cap 適用 EV/FCF 60-80x → EV $2.4T-$3.2T → 股權 $2.4T-$3.2T → 每股 $224–$295，中位 $260。註：DCF 對 AMZN 不適合作 primary，因 capex 變動性大且未來 5 年仍處 ramp 期。

方法 3（賣方共識）：78 位賣方買入占比 92.3%[來源:Finnhub]，4 月內持平 92-93%。假設 12 個月共識 mid-point 約 $325，6M 折現 = $265 + 0.95×($325-$265) = $322。

三方法區間 $224–$322、中位 $285，誠實平均 ~$295。結論目標 $310、區間 $250–$360，對應潛在報酬 +17.0%（區間 -6% ~ +36%）。採三方法誠實中位 $295 後上調至 $310——理由：composite +5 + 賣方 92% 偏多 + AWS / 廣告雙軸結構性擴張 + DCF 對成長期低估，依 SKILL v2 anti-NEUTRAL-bias rule 不再做下行折扣。上修觸發：AWS Q2 +20%+ + Op margin 14% → 升 STRONG_BUY；下修觸發：Q2 連 3 季 adj EPS miss 或 AWS < +15% → 降 NEUTRAL。

評等與依據

6 個月目標價 $310、最新收盤 $265.01，潛在報酬 +17.0%。對應評等規則（>+30% 強買 / +15%–+30% 買入 / -15%–+15% 中立 / <-15% 賣出）為 買入。若目標價上修至 $345 以上則升 STRONG_BUY；若下修至 $225 以下則降 NEUTRAL。

信心 0.65（中）：三方法價差 $224–$322（44%）為中段稍偏高；連 2 季 adj EPS miss + capex 節奏為主要短期變數；composite +5 + 賣方 92% 偏多 + Op margin 結構性擴張為強支撐——符合 SKILL「方法價差 25-60% + 強質性訊號互相抵銷」之中等門檻。
