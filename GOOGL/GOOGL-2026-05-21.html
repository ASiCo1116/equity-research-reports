摘要

Alphabet 是全球最大網路搜尋、影音廣告、雲端基礎設施與基礎模型 AI 的綜合性集團，FY25 全年營收 $402.8B（+15% YoY）[來源:10-K]，三大業務分部為 Google Services（Search、YouTube、Network）、Google Cloud（GCP + Workspace）、Other Bets（Waymo 等）。Q1 FY26 營收 $109.9B（+21.8% YoY）[來源:10-Q]，2026 Google I/O 推出新一代 Gemini 模型與 agent 工具[來源:news]。

論點核心：(1) 營業利潤率自 5y 均 29.7% 升至 TTM 32.7%[來源:Finnhub]、ROE 自 28% 升至 39%[來源:Finnhub]，反映 AI 整合驅動操作槓桿；(2) FY25 CapEx $91.4B（+74% YoY）[來源:10-K]、Q1 FY26 annualized $143B[來源:推算]，AI 基礎設施投資為 Gemini / GCP TPU 多年期競爭力護城河；(3) 賣方買入占比 88.6%（4 月內續升 +3 pp）[來源:Finnhub]，動能強勁，52 週報酬 +132.8%[來源:Finnhub]，剛於 2026-05-18 觸及 52 週高點 $408.61[來源:OHLC]。

給予 中立、6M 目標 $435（區間 $360–480）。最大單一觸發點為 2026-07 底 Q2 FY26 財報：Cloud 營收增速 + AI capex 走勢 + DOJ Search 反壟斷救濟階段裁決進度。若 Cloud Q2 YoY ≥ +35% + DOJ 救濟避免結構性拆分 → 升 BUY；若 GCP 增速跌破 +25% 或 DOJ 命令拆分 Chrome / 預設搜尋分潤合約終止 → 降 SELL。

適合相信「Gemini × Search × Cloud 三引擎複合成長、AI 基礎設施投資具長期回報」、能承受 35% 年波動度（3M ADR std 34.6）的成長型核心配置；不適合對 DOJ 反壟斷風險或 AI 搜尋替代敘事極度敏感的投資人。

產業與業務分析

Alphabet 業務拆解：Google Services（FY25 約占 89% 營收）—Search 廣告 + YouTube 廣告 + Network 廣告 + 訂閱（YouTube Premium / Google One）；Google Cloud（約占 11%）—GCP 基礎設施 + Workspace + Vertex AI / Gemini API；Other Bets（<1%）—Waymo（自駕）、Verily 等[來源:10-K]。產業結構為集中——搜尋全球 ~90% 份額（Bing 與 ChatGPT search 為次），雲端 #3（落後 AWS / Azure），影音 YouTube 全球 #1 訂閱戶與廣告營收。

Tech / SaaS KPI（Q1 FY26）：Cloud 營收—雖未拆出但市場估 $13–14B Q1（+30%+ YoY）[來源:news]；R&D % of revenue FY25 約 14%[來源:推算]；CapEx Q1 FY26 $35.7B、annualized $143B[來源:10-Q]，主要為 TPU + 資料中心；毛利率 Q1 FY26 約 59%（Finnhub TTM 60.4%）[來源:Finnhub]；營運現金流 Q1 FY26 $45.8B（+27% YoY）[來源:10-Q] 但 FCF $10.1B（-47% YoY）因 capex 暴增。10 年週期脈絡：FY16 營收 $90B、FY20 $183B（COVID 後 cloud 加速）、FY22 $283B（廣告週期下行）、FY24 $350B、FY25 $403B[來源:10-K]，5 年營收 CAGR 17%、EBITDA CAGR 20%。Headwinds：(1) DOJ Search 反壟斷案 2025-09 一審判 Search 違反 Sherman Act 第 2 條，救濟階段（Chrome 處分 / 默認搜尋分潤合約）2026 內進行[來源:10-K]；(2) AI 搜尋替代風險（Perplexity、ChatGPT search）；(3) EU DMA 持續罰款風險；(4) AI capex 排擠 FCF（Q1 FCF YoY -47%）。

投資論點（Bull Case）

1. Gemini 2026 + Cloud 加速形成 AI 變現主軸
Google I/O 2026 發布新一代 Gemini 與 agent 工具[來源:news]；UBS / BofA 認為新 AI 工具可推升 Search、Cloud 之外的變現[來源:news]。Cloud Q1 FY26 增速估 +30%+ YoY[來源:news]。
若 Cloud Q2 FY26 YoY 跌破 +25%，或 Gemini 在 LLM 比較基準（如 LMArena、MMLU、AI Index）連續 3 月排名落於前 5 之外，AI 變現論點弱化。
2. 營業利潤率自 FY22 低點結構性回升
FY25 Op margin 32.0% 較 FY22 低點 26.5% 升 +5.5 pp[來源:10-K]；Q1 FY26 Op margin 36.1%（39,696/109,896）[來源:10-Q] 進一步擴張，反映 2023-24 裁員 + AI 自動化雙重貢獻。
若任一季 Op margin 回落 > 3 pp 或裁員 / 重整費用復發 $5B+，論點動搖。
3. 賣方主流強烈偏多、買入占比續升
70 位賣方買入占比 88.6%（4 月內 85.5% → 88.6%）[來源:Finnhub]；近 4 季 3 beats 1 miss，Q3 FY25 +29.4% 大幅超驚奇[來源:Finnhub]。
若 Q2 FY26（2026-07 底）調整 EPS 連續 2 季 miss，或買入占比跌破 80%，動能轉弱。
4. CapEx 雖大但有回報視野
FY25 CapEx $91.4B（+74% YoY）、Q1 FY26 $35.7B[來源:10-Q]；TPU + 自研晶片策略降低對 Nvidia 依賴[來源:news]，並支援 Anthropic 等 Cloud 客戶基礎設施需求。OCF $45.8B Q1 仍創歷史新高[來源:10-Q]。
若 FY26 CapEx 超過 $150B 同時 FCF 持續 YoY 負成長，市場恐質疑投資回收期。

主要風險（Bear Case）

1. DOJ Search 反壟斷救濟階段裁決
2025-09 一審裁定 Search 違反 Sherman Act 第 2 條[來源:10-K]。可能救濟包括：Chrome 處分、限制 Apple / Mozilla 預設搜尋分潤（GS 估值預設搜尋分潤每年帶入 $20B+ 收益）、強制 Android 第三方 search 預設。任一結構性命令對營收 / 估值衝擊 -10% 至 -20%。
機率：中 · 嚴重度：高
2. AI 搜尋介面替代風險
Perplexity、ChatGPT search、Claude search 等 AI 第一介面持續侵蝕 Search 入口；10-K Item 1A 列「市場可能比預期演化更快」[來源:10-K]。長期廣告轉化漏斗可能改變。
機率：中 · 嚴重度：中-高
3. CapEx 規模對 FCF 與股東報酬的壓力
Q1 FY26 FCF $10.1B（-47% YoY）[來源:10-Q]；FY26 全年 CapEx 估 $140B[來源:推算]。若 AI 變現節奏低於投資節奏，FCF/股 將連續多季承壓，影響庫藏與股利成長空間。

估值與目標價

為達成目標價，需要相信什麼

  • Q2 FY26（2026-07 底）營收 ≥ $115B、調整 EPS ≥ $2.80（重回 beat）。
  • Google Cloud Q2 FY26 增速 ≥ +30% YoY 並維持。
  • DOJ Search 救濟裁決不包含 Chrome 結構性拆分或預設搜尋分潤合約全面解除。
  • FY26 CapEx 上限 $145B、FCF 不低於 $60B（FY25 $73B 之 -18% 緩衝範圍）。
  • Gemini 在主要 LLM 排行榜（LMArena / MMLU）維持前 3。

三角驗證 6 個月目標價：

方法 1（multiple × forward EPS）：Finnhub forward 共識 EPS $13.55（$387.66 / PE_fwd 28.6）[來源:推算]。對 Mega-cap AI / Cloud 領導者，採 PE 28–34x 區間 → $379–$461，中位 $420。

方法 2（DCF / FCF 敘述）：FY25 FCF $73.3B、FY26 估 $60–75B（CapEx 壓力 - 但 OCF 持續強勁 +27% YoY）[來源:推算]。EV $4.74T 對 FY26 FCF 中位 $68B = 70x。對 Cloud / AI 高成長期適用 EV/FCF 55–70x → EV $3.7T–$4.8T → 加現金 $38B 減 LTD $77.5B = 股權 $3.66T–$4.76T → 每股 $302–$393，中位 $348。

方法 3（賣方共識）：70 位賣方買入占比 88.6%[來源:Finnhub]、4 月內續升 +3pp。假設 12 個月共識 mid-point 約 $470，6M 折現 = $387.66 + 0.95×($470-$387.66) = $465.9。

三方法區間 $302–$466、平均 $407、加權考慮 DOJ 救濟時點不確定與 CapEx 對 FCF 的壓制，結論目標 $435、區間 $360–$480，對應潛在報酬 +12.2%（區間 -7% ~ +24%）。上修觸發：Cloud Q2 +35%+ YoY + DOJ 救濟避免結構性命令 → 升 BUY；下修觸發：DOJ 命令 Chrome 拆分或預設搜尋分潤合約終止 → 降 SELL。

評等與依據

6 個月目標價 $435、最新收盤 $387.66，潛在報酬 +12.2%。對應評等規則（>+30% 強買 / +15%–+30% 買入 / -15%–+15% 中立 / <-15% 賣出）為 中立。若目標價上修至 $446 以上則升 BUY；若下修至 $329 以下則降 SELL。

信心 0.65（中）：三方法價差 $302–$466（54%），略超 25% bucket 但在 25-60% 區間；DOJ 救濟為 binary 高影響事件、Q2 FY26 為下一個關鍵驗證點—符合 SKILL「方法價差 10–25% 中段、單一事件主導不確定性」之中等門檻。
